# FIFA-19-Exploratory-Data-Analysis-Power-BI-Dashboard
This project focuses on performing Exploratory Data Analysis (EDA) on the FIFA 19 dataset and building an interactive Power BI dashboard to uncover meaningful insights about players, clubs, ratings, wages, positions, and overall performance trends.

The project combines data analysis, data cleaning, and data visualization techniques to transform raw football player data into an easy-to-understand analytical dashboard.
